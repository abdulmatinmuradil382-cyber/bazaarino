# بازارینو — فروشگاه آنلاین

نسخه اولیه حرفه‌ای رابط فروشگاه آنلاین با Next.js + TypeScript + Tailwind CSS.

## اجرا
1. Node.js نصب باشد.
2. داخل این پوشه ترمینال باز کنید.
3. اجرا کنید:
   npm install
   npm run dev
4. مرورگر را باز کنید و به http://localhost:3000 بروید.

## وضعیت
این نسخه شامل رابط فروشگاه، دسته‌بندی، جست‌وجو، فیلتر دسته، کارت محصول و سبد خرید اولیه است.
در مراحل بعد می‌توان Backend، PostgreSQL، حساب کاربری، پنل مدیریت، سفارش، پرداخت و قابلیت‌های AI را اضافه کرد.
